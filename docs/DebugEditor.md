# デバッグエディタ 説明書（Unity風レイアウト）

Debug ビルドで起動すると、Unity と同じような画面構成でゲームを確認・調整できます。
Release ビルドでは表示されません（通常のゲーム画面のみ）。

```
┌───────────────────────────────────────────────────────────┐
│ TuboEngine  Window  Layout  Scene   [▶][⏸][⏭][↻]   FPS 60 │ ← メニューバー / ツールバー
├───────────┬──────────────────────────────┬────────────────┤
│ Hierarchy │                              │ Inspector      │
│           │            Game              │  + 各デバッグ  │
│           │                              │    ウィンドウ  │
├───────────┴──────────────────────────────┤   （タブ）     │
│ Project / Console                        │                │
└──────────────────────────────────────────┴────────────────┘
```

---

## 各ウィンドウ

### Game（中央）
- ゲーム画面です。縦横比を保ったまま、空いた領域いっぱいに表示されます（余白は黒帯）。
- Game ウィンドウ上でのマウス操作はゲーム側に届きます。
- `Input::GetMousePosition()` は **Game ウィンドウ内のゲーム解像度の座標** に自動で変換されます。
  （いままで通り 1280×720 の座標として使えます）
- 一時停止中は左上に「一時停止中」と表示されます。

### Hierarchy（左）
- 一番上に **現在のシーン名**、その下に今そのシーンで出ているデバッグウィンドウが並びます。
- 項目をクリック → そのウィンドウが右のエリアで前面に表示されます。
- 左のチェックボックス → ウィンドウの表示／非表示（`BeginPanel` で作ったウィンドウのみ）。
- 上の検索欄で名前を絞り込めます。
- 「シーン一覧」を開くと、クリックでシーンを切り替えられます。

### Hierarchy のオブジェクト / Inspector での編集
- シーンが `TuboEngine::Editor::Inspect("名前", obj)` で登録したオブジェクトが、Hierarchy の一番上に `[3D] 名前` のように並びます。
- クリックすると Inspector に **位置・回転（度）・拡縮・色** が出て、その場で編集できます。
- 3D オブジェクトを選ぶと、Game 画面に **赤(X)・緑(Y)・青(Z) の矢印** が出ます。矢印をドラッグするとその向きに移動します。

### テクスチャの変更・変更の保存・フォルダ分け
- Inspector の **Texture** 欄に Project から画像をドラッグ（または Project で画像を選んで「Project で選択中の画像を使う」）。
- 実行中に変えたオブジェクトは Hierarchy に **`*`** が付きます。残したい物だけ「この状態を保存」（右クリックでも可）。「変更をすべて保存」でまとめて保存。
  シーンの Initialize で `SceneSaveData::Apply("名前", obj)` を呼んでいれば、次回の起動から反映されます。
- Hierarchy の「+ フォルダ」でフォルダを作り、オブジェクトをドラッグして入れられます（右クリックで名前変更・削除）。

### Timeline（下、Console の隣）
- 選んだオブジェクトの **キーフレームアニメーション** を作れます（Blender のタイムラインと同じ感覚）。
- 時間を合わせて動かし「キーを打つ (I)」→ 時間を変えて繰り返す →「再生」で確認 →「Save」で JSON に保存。
- ◆ はドラッグで時間変更、右クリックで削除・補間の変更。使い方の詳細は `docs/EngineRoadmap.md` の「キーフレームアニメーション」。

### Inspector（右）
- 選択中の項目、現在のシーン、再生状態、FPS、Game ビューの解像度・表示倍率を表示します。
- **各シーン／マネージャのデバッグウィンドウは、このエリアにタブで自動的に並びます。**
  タブをクリックするか、Hierarchy で選択して切り替えてください。

### Project（下）
- `Resources` フォルダの中身を表示します。左がフォルダツリー、右がアイコン一覧です。
- フォルダはダブルクリックで中に入れます。上のパス（`Resources > Textures` など）をクリックすると戻れます。
- アイコンの色はファイルの種類を表します：
  緑=テクスチャ / 青=モデル / オレンジ=音 / 紫=シェーダ / 黄=データ(json等) / 赤=フォント
- **右クリック → 「パスをコピー」** で `Resources/Textures/white.png` のようなパスをコピーできます。
  コードにそのまま貼り付けて使えます。「エクスプローラーで表示」もできます。
- 右上の検索欄は Resources 全体からファイル名で検索します。
- ファイルを追加・削除したら「更新」を押してください。

### Console（下、Project の隣のタブ）
- `TuboEngine::Logger::Log()` で出したログが表示されます。
- 文言に `error` / `failed` / `エラー` / `失敗` を含むと赤（Error）、
  `warning` / `警告` を含むと黄（Warning）で表示されます。
- 右上の `Log / Warning / Error` ボタンで種類ごとに表示を切り替えられます（数字は件数）。
- 「クリア」でログを消去、「全てコピー」でクリップボードへコピーします。

## ツールバー（メニューバー中央）

| ボタン | 動作 | ショートカット |
|---|---|---|
| ▶ 再生 | 一時停止を解除する | Ctrl + Shift + P |
| ⏸ 一時停止 | シーンの更新(Update)を止める。描画と ImGui は動いたまま | Ctrl + Shift + P |
| ⏭ コマ送り | 一時停止して 1 フレームだけ進める | Ctrl + Alt + P |
| ↻ リロード | 今のシーンを作り直す（Finalize → Initialize） | — |

※ 一時停止中に止まるのは `SceneManager::Update()` だけです。入力・ポストエフェクトの更新は続きます。

## メニュー

- **Window**
  - 「全ウィンドウ表示」… OFF にするとデバッグ UI をすべて隠し、ゲーム画面を全画面表示します。
  - Hierarchy / Inspector / Project / Console / Timeline … エディタウィンドウの表示切り替え（✕で閉じた時の再表示もここから）。
  - 個別パネル … `BeginPanel` で作ったウィンドウの表示切り替え。
- **Layout**
  - 「Game ウィンドウに表示 (Unity風)」（**F1**）… OFF にすると以前の表示（ゲーム画面の上にウィンドウが重なる）に戻ります。
  - 「レイアウトをリセット」… ウィンドウの配置を最初の状態に戻します。崩れた時はこれ。
  - 「マウスカーソル」… カーソルの固定方法を選びます（固定しない / ウィンドウ内に固定 / 中央に固定・非表示）。
    - Game 画面を **クリックすると固定**、**Esc で一時解除** します（Unity の Play モードと同じ）。
    - Game ウィンドウ表示中は、Game の画像の範囲に閉じ込めます。
    - **既定は「固定しない」** です。固定するのはモードを切り替えた時（またはゲーム側が `SetCursorMode` した時）だけです。
    - 起動直後や別のウィンドウに切り替えた後は固定されていません。
- **Scene** … シーンの切り替え・リロード。

## レイアウトの変更・保存

- ウィンドウのタブをドラッグすると、好きな場所にドッキング（合体・分割）できます。
- 配置は `project/imgui.ini` に自動保存され、次回起動時も同じ配置になります。
- 新しく出てきたデバッグウィンドウは、自動で Inspector の隣に入ります（ゲーム画面に重なりません）。
  自分でドラッグして外に出したウィンドウは、その起動中はそのままです。

## デバッグウィンドウの作り方（推奨）

`ImGui::Begin` の代わりに `BeginPanel` を使うと、Hierarchy や Window メニューから表示／非表示を切り替えられます。

```cpp
#ifdef USE_IMGUI
	if (TuboEngine::ImGuiManager::GetInstance()->BeginPanel("Player")) {
		ImGui::DragFloat3("Position", &position_.x, 0.1f);
	}
	TuboEngine::ImGuiManager::GetInstance()->EndPanel(); // 必ず対で呼ぶ
#endif
```

`ImGui::Begin("名前")` のままでも Hierarchy には表示され、Inspector の隣に自動で並びます（表示切り替えのチェックボックスだけ出ません）。

### Project からのドラッグ＆ドロップ
Project のアイコンはドラッグできます（ペイロード名 `"ASSET_PATH"`、中身は `Resources/...` のパス文字列）。
自分のウィンドウで受け取る例：

```cpp
ImGui::Button("ここにテクスチャをドロップ");
if (ImGui::BeginDragDropTarget()) {
	if (const ImGuiPayload* payload = ImGui::AcceptDragDropPayload("ASSET_PATH")) {
		std::string path = static_cast<const char*>(payload->Data); // 例: "Resources/Textures/white.png"
	}
	ImGui::EndDragDropTarget();
}
```

## 困った時は

| 症状 | 対処 |
|---|---|
| ウィンドウの配置がぐちゃぐちゃ | Layout → レイアウトをリセット |
| Hierarchy などを ✕ で閉じてしまった | Window メニューからチェックを入れる |
| 昔の表示に戻したい | F1（Layout → Game ウィンドウに表示 を OFF） |
| ゲーム画面を大きく見たい | Window → 全ウィンドウ表示 を OFF |
| マウスがゲームに効かない | マウスが Game ウィンドウの画像の上にあるか確認 |
| マウスが Game 画面から出られない | Esc で解除（Layout → マウスカーソル →「固定しない」で常に解除） |
